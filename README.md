# Hälsostudie

Projektet analyserar data från en hälsostudie

## Miljö
- Python 3.14.7
- Jupyter Notebook
- Pandas
- Matplotlib
- NumPy
- SciPy
- (se `requirements.txt`)

## Kom igång

1. Klona repot:
```bash
git clone <repo-url>
cd <repo-namn>
```
2. Skapa och aktivera virtuell miljö:
```bash
python -m venv .venv
```
3. Installera beroenden:
```bash
python -m pip install -r requirements.txt
```
